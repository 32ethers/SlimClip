# Windows 11 手工验收（尚未执行）

> 仅在隔离测试机上操作复制的视频样本；勿用唯一原片测试「替换」。CI 编译/MSIX 生成不能证明资源管理器真实呈现、安装/卸载或文件同步。

1. 确认 Windows 11 版本、x64、测试包构建编号与公开证书指纹。按 [安装说明](../packaging/INSTALL.md)由测试者**主动**信任证书，再安装完整 MSIX；记录安装结果和系统应用列表中的 SlimClip。
2. 在资源管理器对 `.mp4`、`.mkv`、`.mov` 视频直接右键：检查 Windows 11 **第一层**「压缩视频」展开低、中、高、预估、设置五项；对非视频不显示。选两个视频时三个档位可用，预估应禁用；如需重新登录才出现，记入结果。
3. 用可丢弃的短视频执行三档压缩：检查队列顺序、每项实时进度、输出均为 H.265 MP4、文件同目录、默认保留原片、不放大分辨率。设定 AAC 音轨直接复制；用带非 AAC 与双音轨样本核对输出两条 AAC、语言标签与实际试听同步。
4. 单文件运行预估：观察三档**进度条动态更新**与最终三个预估值；关闭窗口期间继续在托盘运行，并能从托盘重新打开进度窗口。
5. 带字幕或附加视频/数据轨的样本：另存应先提示遗漏并要求确认；选否不生成；替换模式必须拒绝。源文件和已有同名 `.mp4` 冲突时不得覆盖。开启「结果不小于原片时跳过」并验证原片仍在。
6. 在复制样本上单独试替换：同扩展名及 `.mkv` → `.mp4` 两种情形；成功后目标可播放、源/备份策略正确。编码中取消当前任务和托盘「退出」确认后，确认原片仍可播放且无未清理的临时输出。模拟异常恢复仅在确认备份路径后进行，**不做真实断电实验**。
7. 从 Windows「设置 → 应用」卸载，重新打开资源管理器确认菜单消失；核对用户原片和结果均未被卸载器删除。若导入过测试证书，按指纹单独移除，不批量删除其他证书。
