# Windows 11 传统菜单 + EXE 手工验收（尚未执行）

> 在隔离测试机上使用**可丢弃的视频副本**；勿用唯一原片测试「替换」。CI 的 Server 2025 注册检查不能证明 Windows 11 Explorer 真实菜单或音画同步。

1. 确认 Windows 11 x64 与对应 CI 编号，从可信 Actions 获取新版 `SlimClip-EXE-Installer-NO-FFMPEG` 中的 `SlimClip-Setup.exe`。不使用旧 MSIX、`.cer` 或证书导入；未签名 EXE 可能触发 SmartScreen。双击安装，核对「设置 → 应用」中 SlimClip 和当前用户安装目录；记录截图。
2. 对 `.mp4`、`.mkv`、`.mov` 视频右键→**显示更多选项**：检查经典「压缩视频」展开低、中、高、预估、设置五项；非视频不显示。多选两个视频时三档可排队，预估禁用；必要时退出 Explorer/重新登录刷新并记录。**不要求 Windows 11 第一层新式菜单**。
3. 首次任务在没有工具时必须征询用户对上游 FFmpeg GPLv3 的知情同意；点「否」不能修改源片。点「是」应显示下载/校验/安装阶段，从官网取对应版本，工具只进入当前用户目录；另测设置中选择已有 ffmpeg.exe/ffprobe.exe，失败路径显示可理解错误。不应在安装目录找到 FFmpeg 二进制。
4. 「设置」保留固定 H.265 MP4、三个档位的 CRF/最高高度、另存/替换、跳过变大及 FFmpeg 文件夹。短视频依次测试三档：队列、每项真实进度、MP4/HEVC、同目录保留原片、不放大分辨率。AAC 源轨复制，非 AAC 和混合双轨输出保留轨数/语言标签，**实际试听音画同步**。
5. 单文件预估时观察三档**动态更新的进度条**和最后三个大小；关窗后托盘继续工作，从托盘恢复窗口。取消当前任务和托盘「退出」确认后，检查没有损坏原片。
6. 带字幕/额外轨道样本：另存必须先提示可能省略并确认；点否不处理；替换模式直接拒绝。同名 MP4 已存在不能覆盖；开启跳过变大输出。只用视频副本测试同扩展名替换和 MKV→MP4，检查可播放文件、备份/恢复日志及异常情况下原片安全，不做真实断电实验。
7. 先从托盘退出，再从「设置 → 应用」卸载；重新打开资源管理器确认传统菜单消失，HKCU 自有注册键与程序目录移除，**用户视频/压缩结果/设置/下载工具保留**。如曾手动信任旧 MSIX 证书，确认精确指纹后单独移除；不要批量删证书或视频。测试升级时按同样步骤核对菜单无重复。
